# Worldbuilder
**A community driven 3D sandbox game inspired by Blocksworld and other similar games.**

Join the Discord server: https://discord.com/invite/akwqENkYBv

# OFFICIAL CONTRIBUTION GUIDE (Windows/Mac):

## Setting up

1. [Create a GitHub account](https://github.com/signup) if you do not have one.
2. [Download the Godot engine](https://godotengine.org/download/preview/). This is a link to their preview builds, as the game always uses the latest beta version.
3. [Download GitHub Desktop](https://github.com/apps/desktop).

## Creating a fork and downloading the project

4. Open the Worldbuilder repository on a web browser, and click the "Fork" button in the top right corner. 
5. Make the repository name the name of your contribution or change, set the owner to yourself, and set the description to anything you'd like. Then click the green "Create fork" button.
6. Open your new fork, click the green "Code" button, and select "Open with GitHub Desktop".
7. Choose somewhere on your computer where you would like to store the project, and click "Clone". This will download the project to your computer.
8. Once the project has finished downloading, open GitHub Desktop and click "Create a New Branch". Give your branch a name describing what you're working on.

## Making your changes

9. Open Godot.
10. Import the project by selecting the project.godot file inside the folder where you downloaded the repository.
11. Make whatever modifications you would like to contribute to the project and save your changes.

## Uploading your changes

12. Open GitHub Desktop. Your changes should automatically appear in the "Changes" tab.
13. In the bottom-left corner, enter a short description of your changes in the "Summary" field.
14. Click "Commit to [your branch name]". This will save your changes locally.
15. Click "Push origin" at the top of GitHub Desktop. This will upload your changes to your GitHub fork.

## Making a pull request

16. Once your changes have been uploaded, click "Create Pull Request" in GitHub Desktop. This will open GitHub in your web browser.
17. Review the changes being submitted. Make sure the base repository is the official Worldbuilder repository, and the base branch is main.
18. Give your pull request a descriptive title and explain what you changed. Click "Create pull request".

1. [Create a GitHub account](https://github.com/signup) if you do not have one.
2. [Download the Godot engine](https://godotengine.org/download/preview/). This is a link to their preview builds, as the game always uses the latest beta version.
3. Open the terminal, navigate to the directory where you would like to store the project, and use the command "git clone https://github.com/JAGamer001/Worldbuilder".
4. Open Godot, click the "Import" button, and select the project folder you have just downloaded.
