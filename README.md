# Worldbuilder
**A community driven 3D sandbox game inspired by Blocksworld and other similar games.**

Join the Discord server: https://discord.com/invite/akwqENkYBv

# OFFICIAL CONTRIBUTION GUIDE (Windows/Mac):

## Setting up

1. [Create a GitHub account](https://github.com/signup) if you do not have one.
2. [Download the Godot engine](https://godotengine.org/download/preview/). This is a link to their preview builds, as the game always uses the latest beta version. Get the Standard install for your operating system.
3. [Download GitHub Desktop](https://github.com/apps/desktop), and log in.

## Creating a fork and downloading the project

4. Open the Worldbuilder repository on a web browser, and click the **"Fork"** button. 
5. Make the repository name the name of your contribution or change, and set the description to anything you'd like. Then click the green **"Create fork"** button.
6. Open your new fork, click the green **"Code"** button, and select **"Open with GitHub Desktop"**.
7. Choose somewhere on your computer where you would like to store the project, and click **"Clone"**. This will download the project to your computer.

## Making your changes

9. Open Godot.
10. Click on the **"Import"** button at the top, navigate to where you have saved your fork, and select the **"project.godot"** file inside the folder.
11. Make whatever modifications you would like and save your changes.

## Uploading your changes

12. Open GitHub Desktop. Your changes should automatically appear in the "Changes" tab. 
13. Click **"Commit to main"**. This will save your changes locally.
14. Click **"Push to origin"** at the top of GitHub Desktop. This will upload your changes to your GitHub fork.
15. Repeat this regularly as you make changes to your fork.

## Making a pull request

16. Once you are satisfied with your changes, navigate to your fork's GitHub page on a web browser.
17. Click on the "Pull requests" tab, and click the green "New pull request" button.
18. Review the changes being submitted. Make sure the base repository is the official Worldbuilder repository, and the base branch is main.
19. Give your pull request an appropriate title and description. Click "Create pull request".
20. Patiently wait for me to eventually merge your fork with the main branch.

# OFFICIAL CONTRIBUTION GUIDE (LINUX, WIP):
1. [Create a GitHub account](https://github.com/signup) if you do not have one.
2. [Download the Godot engine](https://godotengine.org/download/preview/). This is a link to their preview builds, as the game always uses the latest beta version.
3. Open the terminal, navigate to the directory where you would like to store the project, and use the command "git clone https://github.com/JAGamer001/Worldbuilder".
4. Open Godot, click the "Import" button, and select the project folder you have just downloaded.
